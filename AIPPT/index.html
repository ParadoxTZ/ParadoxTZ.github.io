最简单：Marp

介绍

Marp是一个非常简单（简洁）的PPT生成方式，他直接基于你的Markdown格式来编译生成PPT，它的核心思想跟Latex一样，是“内容与样式分离”。你只管用最纯粹的Markdown内容，排版、美化、对齐这些破事儿，交给预设好的theme去操心。而这样同样给予了我们充分地使用AI(LLM)来对其进行修改的空间，因为AI(LLM)产出的同样也是一份Markdown文件，而不是像NotebookLM或Nanobanana Pro那样的图片。

用它产生出来的PPT大概长这样：

所以这样你们就能理解为什么我说这是“糊弄组会的最好PPT生成方法”了：因为组会上很多老师对格式的要求没有那么严格，你把内容、过程、结果这些写清晰就行。而真要到了严肃使用PPT演讲，比如会议、答辩等场合，Markdown本身的弱格式极大地限制了PPT优美的上限。

优缺点与教程

优势：

  1. 和Markdown衔接流畅，格式定义和使用方法非常简单，上手较快
  2. 在AI生成不满意的地方可以轻松介入调整
  3. 他本质是Markdown渲染，不是画图，所以不会像AI绘画一样出现渲染问题。

缺点：

  1. Markdown本身是一种弱格式的轻量化文本标记语言。所以他对格式的定义比较弱，美观性不足，格式和页面美化本身玩不出花来
  2. 现在没有比较完善的模板网页合集，都只能在github上自己找

Marp是本文中唯一一个有我自己写的完整教程的方法，见：【Marp!】利用Markdown+LLM的简易PPT工作流，糊弄组会的最好PPT生成方法！ | Paradox’s Website。

最智能：Claude Design

介绍

Claude在前端的设计能力应该是现在有目共睹的了，Claude Design就是Claude专门为前端UI开发的一个能力，他的功能远不止于PPT，还包括网页前端、产品设计、宣传海报等等。

为什么说他是最智能，因为他能给你生成一份“问卷”来明确你的具体需求，也就是说你不需要费大力气来写各种各样的提示词。然后他创建出的PPT（包括前端等）不是不可更改的图片，而是模块化的、可调可删的Block，调节自由度高。比如字体小了，你可以直接放大；有一个东西不想要，直接删了就行。

当然Claude的缺点也是人尽皆知，对中国用户很不友好，并且贵的要命。Claude Design目前免费版的Claude是几乎不能用的，必须充Pro或者Max，然后Design的额度是单独计费的（和日常问答分开来），并且这个额度消耗的奇快无比。

如果用一句话总结Claude Design，那么就是：

抛开额度不谈，它确实非常实用。

最出名：PPT Master SKILL

丢进一份 PDF、DOCX、网址或 Markdown，拿回一份原生可编辑的 PPT——真正的形状、真正的文本框、真正的图表，不是图片。点击任何元素即可编辑。截止写教程的今日，该项目在Github上有16.7k Star。

PPT Master 是 harness，不是完整的 agent。 harness + model = agent——工具负责工作流，模型决定上限。要组成真正高质量的 agent，推荐组合是：Claude + AI 生图（gpt-image-2）。其他模型能跑流程，但达不到同等质量上限。效果不理想，请先换模型，不要质疑 harness。（摘自README原文）

模板复刻 —— 把任何一份你喜欢的PPT丢给 AI，一句“用 /create-template 复刻成模板”，就能拿到一套可被 PPT Master 直接调用的页面布局，封面/章节/装饰繁复的页面都能稳定还原。从此你不再受限于内置模板：公司品牌 deck、客户中标模板、找的高质量参考稿，都能一键变成你的私人模板库。

多的就不说了，在它的Github中有详细的安装、配置和使用教程：hugohe3/ppt-master: AI generates natively editable PPTX from any document — real PowerPoint shapes with native animations, not images · by Hugo He

**优点：**神

**缺点：**安装和配置稍微有点麻烦

最AI：HTML PPT SKILL

介绍

  • 你的下一个PPT，又何必是PPT？PPT实际上只是幻灯片的一个载体而已，就像Latex和Word都是文字的载体一样。这么多年来PPT一只霸占了幻灯片的生态，跟Word的盛行本质上是一样的，因为他具备了一个极其适合人类编辑的特点：所见即所得。

  • 过去很久时间内，我们一只希望AI来适应我们的习惯，让AI来画图、来生成PPT，却发现效果总是不尽如人意。为什么？因为视觉和图片从来不是AI的强项，代码才是。那么哪个工具是基于代码的幻灯片放映工具？

HTML

  • HTML-PPT：一款专业级的 Agent Skill，在Github上有3.9k Star，让 AI 做出真正能打的 HTML 演示文稿。 36 套主题、15 套完整 deck 模板**、31 种页面布局、**47 个动效 (27 个 CSS + 20 个 Canvas FX)，加上全新的演讲者模式 —— 像素级 完美预览 + 逐字稿提词器 + 计时器。纯静态 HTML/CSS/JS，无需构建。

优缺点与教程

优势：

  1. 安装和使用方便，只需要下载该Skill然后提供对应信息即可。
  2. 更改主题方便（只需要按“T”即可一键更换主题），自带演讲者模式（按“S”进入）

缺点：

  1. 吃LLM能力，目前应该Claude Opus 4.6是独一档，Kimi K2.5在AI方面的能力也还可以
  2. 我感觉比较缺细节，AI味也比较浓

特点：（说不上优缺点）

  1. 卡片化布局，大量使用卡片结构

**仓库地址：**https://github.com/lewislulu/html-ppt-skill
